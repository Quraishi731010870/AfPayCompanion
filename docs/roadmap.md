# Roadmap

1. **Foundation — implemented:** design system, routing, localization, onboarding, navigation, core screens and states.
2. **Public directory — foundation implemented:** organizations, repository abstraction, search, favorites, detail/source metadata. Next: services, richer filters and verified datasets.
3. **Maps:** contextual permission, provider abstraction, verified ATM/POS/agent/branch data, clustering and directions.
4. **Help:** status explainer, configurable troubleshooter, dispute preparation and calculators.
5. **Education:** articles, categories, security guides and offline reading.
6. **Notifications:** FCM, topic preferences, center and deep links.
7. **Backend:** FastAPI, PostgreSQL, Redis, Alembic, REST, admin authentication and RBAC.
8. **Admin:** React/TypeScript/MUI dashboard, CRUD, audit, reporting and analytics.
9. **Hardening:** cache database, accessibility QA, integration tests, security/performance review, monitoring and release operations.
